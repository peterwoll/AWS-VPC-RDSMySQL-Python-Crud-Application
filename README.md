Summary of Project:


1. AWS VPC, EC2, RDS MySQL and Python Database Application

2. Designed and deployed a secure AWS database environment using Amazon VPC, EC2, and Amazon RDS MySQL.

3. Configured a custom VPC with public and private subnets across two Availability Zones.

4. Deployed an EC2 Linux instance to provide controlled access to a private RDS MySQL database.

5. Configured security groups and database subnet groups.

6. Created and populated a MySQL customer database.

7. Developed and tested a Python application using MySQL Connector/Python to retrieve customer records from Amazon RDS.

8. Technologies: AWS VPC, Amazon EC2, Amazon RDS, MySQL, Python, Linux, SSH, IAM, Security Groups.
